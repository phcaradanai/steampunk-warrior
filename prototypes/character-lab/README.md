# Character Atelier — ตัวต้นแบบ 01

คำถาม: ท่าทาง บุคลิก และอุปกรณ์ที่เห็นบนตัว ไปในทิศทางที่ผู้ใช้ต้องการหรือไม่?

เปิด `Open-Character-Lab.command` บนเครื่องนี้ หรือเปิด project.godot ใน Godot 4.7 แล้วกด Run.

- ปุ่มด้านล่าง: ยืน เดินอยู่กับที่ โจมตี รับแรง ป้องกัน กลับด้าน หยุด/เล่น
- ด้านขวา: อาวุธ 3 แบบ ศีรษะ 3 แบบ ชุด 3 แบบ และไม่มีโล่/โล่ 2 แบบ
- บุคลิก: สงบ พร้อมสู้ เหนื่อยล้า เปลี่ยนการถืออาวุธ การก้ม และการหายใจ
- เลื่อนความเร็วเพื่อดูท่าช้าได้
- A/D เลือกเดินและทิศ ปล่อยเพื่อหยุด; Space โจมตี H รับแรง G ป้องกัน

เป็นงานทดลองรูปทรงแบบเวกเตอร์และข้อต่อ ยังไม่ใช่งานภาพสุดท้าย ไม่โหลดหรือเปลี่ยนเซฟเกมจริง ไม่มีระบบต่อสู้ ดาเมจ หรือเสียง การเดินเป็นการเดินอยู่กับที่เพื่อเทียบชุดง่าย และอาวุธยังใช้จังหวะโจมตีพื้นฐานร่วมกัน ต้องปรับท่าแยกตามน้ำหนักหลังเลือกทิศทางภาพแล้ว

ตรวจด้วย check.gd: เปลี่ยนทุกตัวเลือกอุปกรณ์ การเคลื่อนท่าโจมตี การขัดจังหวะ และการคืนท่าหลังรับแรงผ่าน บน Godot 4.7.2 / Apple M1. ตรวจผ่านหน้าต่างจริงว่าเลือกค้อนแล้วภาพเปลี่ยน และค้อนตามมือระหว่างเดิน.

เกณฑ์รับ: ผู้ใช้เห็นการงอแขนขา อ่านอารมณ์ได้ และเปลี่ยนของแล้วเห็นความต่างชัด ก่อนขยายไปทั้งเกม งานต้นแบบนี้ยังไม่ถือเป็นการอนุมัติรูปแบบภาพโดยผู้ใช้
