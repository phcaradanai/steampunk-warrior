# 0.1.1 — room input repair

User reported that advancing to the next room failed. The player's actual0.1.0log records `Cannot call method 'set_input_as_handled' on a null value` at WorldView._unhandled_input:98. Prior model/campaign checks did not exercise this keyboard-to-scene lifecycle. The earlier playable smoke used the on-screen button for doors and missed it.
